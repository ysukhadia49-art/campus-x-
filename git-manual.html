The 4 Stages of Git Architecture

Git does not immediately save changes straight to the cloud. Instead, files move through 4 progressive states:

1

Working Dir

Your actual project files, edits, and active code.

You write code
2

Staging Area

The "index" buffer where you review files to commit.

git add .
3

Local Repo

Permanent snapshots saved in your hidden .git folder.

git commit -m "..."
4

Remote (GitHub)

Cloud repository for backups and collaboration.

git push

30-Second Quick Start

To create and publish a Git repository in any project, run these 5 commands in order:

powershell / bash
$# 1. Initialize a new repo with main branch
$git init -b main
$# 2. Stage all files (respecting .gitignore)
$git add .
$# 3. Create your first commit
$git commit -m "Initial commit: Project setup"
$# 4. Link with your remote GitHub repo
$git remote add origin https://github.com/username/repo-name.git
$# 5. Push to GitHub
$git push -u origin main

Complete Step-by-Step Tutorial

1

Configure Your Git Identity

Git embeds your name and email in every commit history. Set this once on your computer:

Identity Setup
$git config --global user.name "Your Name"
$git config --global user.email "you@example.com"
2

Configure .gitignore

Always exclude temporary files, large compiled files (like APKs), dependencies (node_modules/), and secrets (.env):

.gitignore Example
node_modules/
.env
*.apk
www/
*.log
3

Initialize Repository & Check Status

Turn the folder into a Git repository and view what files are detected:

Initialize & Status
$git init -b main
$git status
4

Stage & Commit

Stage the changes with git add ., then commit a clean snapshot with an informative message:

Stage & Commit
$git add .
$git commit -m "Initial commit: CampusX AI Frontend project setup"

How to Connect & Push to GitHub

  1. Visit github.com/new.
  2. Enter repository name: CampusX-AI-Frontend.
  3. Leave "Add a README", ".gitignore", and "License" UNCHECKED (since you already have them locally).
  4. Click Create repository.
  5. Copy your HTTPS URL and run:
Connect & Push
$git remote add origin https://github.com/YOUR-USERNAME/CampusX-AI-Frontend.git
$git branch -M main
$git push -u origin main

GitHub Authentication Note:

GitHub no longer accepts account passwords in the terminal. When prompted for password, paste a Personal Access Token (classic) from GitHub Settings > Developer settings > Personal access tokens with the repo checkbox checked.

Git Everyday Cheat Sheet

Category Command Description
Status git status Shows untracked, modified, and staged files.
Staging git add . Stages all new and modified files for commit.
Commit git commit -m "msg" Takes a permanent snapshot of staged changes.
History git log --oneline -n 5 Shows the last 5 commits in compact form.
Push git push origin main Sends local commits to GitHub.
Pull git pull origin main Downloads and integrates changes from GitHub.
Branching git checkout -b feature-name Creates and switches to a new working branch.
Undo Staging git restore --staged <file> Unstages a file without losing its edits.

Common Errors & Fast Fixes

Error: "fatal: remote origin already exists"

Fix by removing the old remote link or updating it:

git remote set-url origin https://github.com/username/new-repo.git

Error: "Updates were rejected because the remote contains work..."

This happens if GitHub already has files (like a README). Pull and reconcile first:

git pull origin main --rebase then git push origin main
